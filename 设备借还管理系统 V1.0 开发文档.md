## 1. 项目概述
### 1.1 项目简介
设备借还管理系统是一款基于 Electron + Umi.js 开发的本地离线桌面应用，主要面向实验室管理教师，提供设备借还全流程管理、逾期提醒、资产统计等功能。

### 1.2 技术栈
| 技术分类 | 技术选型 | 版本要求 |
| :---: | :---: | :---: |
| 桌面容器 | Electron | ^25.0.0 |
| 应用框架 | Umi.js | ^4.0.0 |
| 前端库 | React | ^18.0.0 |
| UI 组件库 | Ant Design | ^5.0.0 |
| 状态管理 | dva / useModel | - |
| 本地数据库 | sql.js | ^1.8.0 |
| 开发语言 | TypeScript | ^5.0.0 |
| 图表库 | Ant Design Charts | ^1.4.0 |


### 1.3 系统架构
```plain
┌─────────────────────────────────────────┐
│          Electron Main Process          │
│  ┌───────────────────────────────────┐  │
```

## 4. 数据库设计
### 4.1 数据库文件位置
+ **开发环境**: `userData/dev-database.sqlite`
+ **生产环境**: `userData/database.sqlite`
+ **userData 路径**: 
    - Windows: `C:\Users\<username>\AppData\Roaming\device-management-system`
    - macOS: `~/Library/Application Support/device-management-system`

### 4.2 表结构设计
#### 4.2.1 设备表 (devices)
```sql
CREATE TABLE IF NOT EXISTS devices (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  code TEXT UNIQUE NOT NULL,              -- 设备编号
  name TEXT NOT NULL,                     -- 设备名称
  brand TEXT,                             -- 设备品牌
  model TEXT,                             -- 规格型号
  price REAL,                             -- 单价
  location TEXT,                          -- 存放地点
  status TEXT DEFAULT 'available',        -- 设备状态: available/borrowed
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- 索引
CREATE INDEX idx_devices_code ON devices(code);
CREATE INDEX idx_devices_name ON devices(name);
CREATE INDEX idx_devices_status ON devices(status);
```

**字段说明**：

| 字段 | 类型 | 约束 | 说明 |
| :---: | :---: | :---: | :---: |
| id | INTEGER | PRIMARY KEY | 自增主键 |
| code | TEXT | UNIQUE, NOT NULL | 设备编号，全局唯一 |
| name | TEXT | NOT NULL | 设备名称/类型 |
| brand | TEXT | - | 设备品牌/厂商 |
| model | TEXT | - | 规格型号 |
| price | REAL | - | 单价（元） |
| location | TEXT | - | 存放地点 |
| status | TEXT | DEFAULT 'available' | 状态：available（可借）、borrowed（已借出） |
| created_at | DATETIME | DEFAULT | 创建时间 |
| updated_at | DATETIME | DEFAULT | 更新时间 |


#### 4.2.2 借还记录表 (borrow_records)
```sql
CREATE TABLE IF NOT EXISTS borrow_records (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  device_id INTEGER NOT NULL,             -- 设备ID
  borrower_name TEXT NOT NULL,            -- 借用人姓名
  borrower_class TEXT NOT NULL,           -- 班级
  borrower_student_id TEXT NOT NULL,      -- 学号
  borrower_phone TEXT NOT NULL,           -- 联系方式
  borrow_time DATETIME NOT NULL,          -- 借出时间
  return_deadline DATETIME NOT NULL,      -- 应还时间
  actual_return_time DATETIME,            -- 实际归还时间
  notified INTEGER DEFAULT 0,             -- 是否已通知: 0/1
  notified_at DATETIME,                   -- 通知时间
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (device_id) REFERENCES devices(id)
);

-- 索引
CREATE INDEX idx_borrow_device_id ON borrow_records(device_id);
CREATE INDEX idx_borrow_student_id ON borrow_records(borrower_student_id);
CREATE INDEX idx_borrow_return_deadline ON borrow_records(return_deadline);
CREATE INDEX idx_borrow_actual_return ON borrow_records(actual_return_time);
```

**字段说明**：

| 字段 | 类型 | 约束 | 说明 |
| :---: | :---: | :---: | :---: |
| id | INTEGER | PRIMARY KEY | 自增主键 |
| device_id | INTEGER | NOT NULL, FK | 关联设备ID |
| borrower_name | TEXT | NOT NULL | 借用人姓名 |
| borrower_class | TEXT | NOT NULL | 班级 |
| borrower_student_id | TEXT | NOT NULL | 学号 |
| borrower_phone | TEXT | NOT NULL | 联系方式（手机号） |
| borrow_time | DATETIME | NOT NULL | 借出时间 |
| return_deadline | DATETIME | NOT NULL | 应还时间 |
| actual_return_time | DATETIME | - | 实际归还时间（NULL表示未归还） |
| notified | INTEGER | DEFAULT 0 | 是否已通知：0（未通知）、1（已通知） |
| notified_at | DATETIME | - | 通知时间 |
| created_at | DATETIME | DEFAULT | 创建时间 |

### 4.3 数据库初始化代码
```javascript
// electron/services/database.js
const initSqlJs = require('sql.js');
const fs = require('fs');
const path = require('path');
const { app } = require('electron');
const bcrypt = require('bcryptjs');

let db = null;
const isDev = process.env.NODE_ENV === 'development';
const dbFileName = isDev ? 'dev-database.sqlite' : 'database.sqlite';
const dbPath = path.join(app.getPath('userData'), dbFileName);

async function initDatabase() {
  try {
    const SQL = await initSqlJs();
    
    // 加载或创建数据库
    if (fs.existsSync(dbPath)) {
      const buffer = fs.readFileSync(dbPath);
      db = new SQL.Database(buffer);
      console.log('Database loaded from:', dbPath);
    } else {
      db = new SQL.Database();
      await createTables();
      saveDatabase();
      console.log('Database created at:', dbPath);
    }
    
    // 定期保存数据库（每5分钟）
    setInterval(saveDatabase, 5 * 60 * 1000);
    
    return db;
  } catch (error) {
    console.error('Database initialization failed:', error);
    throw error;
  }
}

async function createTables() {
  // 创建设备表
  db.run(`
    CREATE TABLE IF NOT EXISTS devices (
      id INTEGER PRIMARY KEY AUTOINCREMENT,
      code TEXT UNIQUE NOT NULL,
      name TEXT NOT NULL,
      brand TEXT,
      model TEXT,
      price REAL,
      location TEXT,
      status TEXT DEFAULT 'available',
      created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
      updated_at DATETIME DEFAULT CURRENT_TIMESTAMP
    )
  `);
  
  db.run(`CREATE INDEX IF NOT EXISTS idx_devices_code ON devices(code)`);
  db.run(`CREATE INDEX IF NOT EXISTS idx_devices_name ON devices(name)`);
  db.run(`CREATE INDEX IF NOT EXISTS idx_devices_status ON devices(status)`);
  
  // 创建借还记录表
  db.run(`
    CREATE TABLE IF NOT EXISTS borrow_records (
      id INTEGER PRIMARY KEY AUTOINCREMENT,
      device_id INTEGER NOT NULL,
      borrower_name TEXT NOT NULL,
      borrower_class TEXT NOT NULL,
      borrower_student_id TEXT NOT NULL,
      borrower_phone TEXT NOT NULL,
      borrow_time DATETIME NOT NULL,
      return_deadline DATETIME NOT NULL,
      actual_return_time DATETIME,
      notified INTEGER DEFAULT 0,
      notified_at DATETIME,
      created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
      FOREIGN KEY (device_id) REFERENCES devices(id)
    )
  `);
  
  db.run(`CREATE INDEX IF NOT EXISTS idx_borrow_device_id ON borrow_records(device_id)`);
  db.run(`CREATE INDEX IF NOT EXISTS idx_borrow_student_id ON borrow_records(borrower_student_id)`);
  db.run(`CREATE INDEX IF NOT EXISTS idx_borrow_return_deadline ON borrow_records(return_deadline)`);
  
  // 创建用户表
  db.run(`
    CREATE TABLE IF NOT EXISTS users (
      id INTEGER PRIMARY KEY AUTOINCREMENT,
      username TEXT UNIQUE NOT NULL,
      password TEXT NOT NULL,
      password_hint TEXT,
      created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
      updated_at DATETIME DEFAULT CURRENT_TIMESTAMP
    )
  `);
  
  // 插入默认用户（密码: admin123）
  const hashedPassword = bcrypt.hashSync('admin123', 10);
  db.run(
    `INSERT OR IGNORE INTO users (username, password, password_hint) VALUES (?, ?, ?)`,
    ['admin', hashedPassword, '默认密码：admin123']
  );
  
  console.log('Database tables created successfully');
}

function saveDatabase() {
  if (db) {
    try {
      const data = db.export();
      const buffer = Buffer.from(data);
      fs.writeFileSync(dbPath, buffer);
      console.log('Database saved at:', new Date().toISOString());
    } catch (error) {
      console.error('Database save failed:', error);
    }
  }
}

function getDatabase() {
  if (!db) {
    throw new Error('Database not initialized');
  }
  return db;
}

// 应用退出时保存数据库
app.on('before-quit', () => {
  console.log('Saving database before quit...');
  saveDatabase();
});

module.exports = {
  initDatabase,
  getDatabase,
  saveDatabase,
};
```

## 5. API 接口文档
### 5.1 IPC 通信协议

### 5.3 设备管理 API
#### 5.3.1 查询设备列表
**Channel**: `device:list`

**请求参数**:

```typescript
interface DeviceListParams {
  code?: string;        // 设备编号（模糊搜索）
  name?: string;        // 设备名称（模糊搜索）
  brand?: string;       // 设备品牌
  status?: 'available' | 'borrowed' | '';  // 设备状态
  page?: number;        // 页码（从1开始）
  pageSize?: number;    // 每页数量
}
```

**响应数据**:

```typescript
interface DeviceListResponse {
  success: true;
  data: {
    list: Device[];
    total: number;
    page: number;
    pageSize: number;
  };
}

interface Device {
  id: number;
  code: string;
  name: string;
  brand: string;
  model: string;
  price: number;
  location: string;
  status: 'available' | 'borrowed';
  created_at: string;
  updated_at: string;
}
```

**示例代码**:

```typescript
// 主进程 (electron/services/deviceService.js)
const { ipcMain } = require('electron');
const { getDatabase } = require('./database');

ipcMain.handle('device:list', async (event, params = {}) => {
  try {
    const db = getDatabase();
    const { code, name, brand, status, page = 1, pageSize = 20 } = params;
    
    let sql = 'SELECT * FROM devices WHERE 1=1';
    const sqlParams = [];
    
    if (code) {
      sql += ' AND code LIKE ?';
      sqlParams.push(`%${code}%`);
    }
    
    if (name) {
      sql += ' AND name LIKE ?';
      sqlParams.push(`%${name}%`);
    }
    
    if (brand) {
      sql += ' AND brand = ?';
      sqlParams.push(brand);
    }
    
    if (status) {
      sql += ' AND status = ?';
      sqlParams.push(status);
    }
    
    // 查询总数
    const countSql = sql.replace('SELECT *', 'SELECT COUNT(*) as total');
    const countResult = db.exec(countSql, sqlParams);
    const total = countResult[0]?.values[0]?.[0] || 0;
    
    // 分页查询
    sql += ' ORDER BY created_at DESC LIMIT ? OFFSET ?';
    sqlParams.push(pageSize, (page - 1) * pageSize);
    
    const result = db.exec(sql, sqlParams);
    const columns = result[0]?.columns || [];
    const values = result[0]?.values || [];
    
    const list = values.map(row => {
      const obj = {};
      columns.forEach((col, index) => {
        obj[col] = row[index];
      });
      return obj;
    });
    
    return {
      success: true,
      data: { list, total, page, pageSize }
    };
  } catch (error) {
    console.error('device:list error:', error);
    return {
      success: false,
      error: error.message
    };
  }
});

// 渲染进程 (src/services/device.ts)
const { ipcRenderer } = window.require('electron');

export async function listDevices(params?: DeviceListParams) {
  return await ipcRenderer.invoke('device:list', params);
}
```

#### 5.3.2 创建设备
**Channel**: `device:create`

**请求参数**:

```typescript
interface CreateDeviceParams {
  code: string;
  name: string;
  brand?: string;
  model?: string;
  price?: number;
  location?: string;
}
```

**响应数据**:

```typescript
{
  success: true;
  data: { id: number };
  message: '设备创建成功';
}
```

**主进程实现**:

```javascript
ipcMain.handle('device:create', async (event, params) => {
  try {
    const db = getDatabase();
    const { code, name, brand, model, price, location } = params;
    
    // 检查设备编号是否已存在
    const checkResult = db.exec('SELECT id FROM devices WHERE code = ?', [code]);
    if (checkResult[0]?.values.length > 0) {
      return {
        success: false,
        error: '设备编号已存在'
      };
    }
    
    // 插入设备
    db.run(
      `INSERT INTO devices (code, name, brand, model, price, location) 
       VALUES (?, ?, ?, ?, ?, ?)`,
      [code, name, brand || '', model || '', price || 0, location || '']
    );
    
    // 获取插入的ID
    const idResult = db.exec('SELECT last_insert_rowid() as id');
    const id = idResult[0]?.values[0]?.[0];
    
    saveDatabase();
    
    return {
      success: true,
      data: { id },
      message: '设备创建成功'
    };
  } catch (error) {
    console.error('device:create error:', error);
    return {
      success: false,
      error: error.message
    };
  }
});
```

**主进程实现**:

```javascript
ipcMain.handle('stats:dashboard', async () => {
  try {
    const db = getDatabase();
    
    // 设备总数
    const totalResult = db.exec('SELECT COUNT(*) as count FROM devices');
    const totalDevices = totalResult[0]?.values[0]?.[0] || 0;
    
    // 在借设备数
    const borrowedResult = db.exec(
      "SELECT COUNT(*) as count FROM devices WHERE status = 'borrowed'"
    );
    const borrowedDevices = borrowedResult[0]?.values[0]?.[0] || 0;
    
    // 可借设备数
    const availableDevices = totalDevices - borrowedDevices;
    
    // 逾期设备数
    const overdueResult = db.exec(`
      SELECT COUNT(*) as count FROM borrow_records 
      WHERE actual_return_time IS NULL 
      AND datetime(return_deadline) < datetime('now')
    `);
    const overdueDevices = overdueResult[0]?.values[0]?.[0] || 0;
    
    // 设备类型分布
    const typeDistResult = db.exec(`
      SELECT name, COUNT(*) as count 
      FROM devices 
      GROUP BY name
    `);
    const deviceTypeDistribution = (typeDistResult[0]?.values || []).map(row => ({
      name: row[0],
      value: row[1]
    }));
    
    // 各类型借出状态
    const borrowStatusResult = db.exec(`
      SELECT 
        d.name,
        SUM(CASE WHEN d.status = 'borrowed' THEN 1 ELSE 0 END) as borrowed,
        SUM(CASE WHEN d.status = 'available' THEN 1 ELSE 0 END) as available
      FROM devices d
      GROUP BY d.name
    `);
    const borrowStatusByType = (borrowStatusResult[0]?.values || []).map(row => ({
      type: row[0],
      borrowed: row[1],
      available: row[2]
    }));
    
    // 近期归还设备（7天内）
    const upcomingResult = db.exec(`
      SELECT 
        d.name as device_name,
        br.borrower_name,
        CAST((julianday(br.return_deadline) - julianday('now')) AS INTEGER) as days_remaining,
        br.return_deadline
      FROM borrow_records br
      JOIN devices d ON br.device_id = d.id
      WHERE br.actual_return_time IS NULL
      AND datetime(br.return_deadline) >= datetime('now')
      AND datetime(br.return_deadline) <= datetime('now', '+7 days')
      ORDER BY br.return_deadline ASC
      LIMIT 10
    `);
    const upcomingReturns = (upcomingResult[0]?.values || []).map(row => ({
      device_name: row[0],
      borrower_name: row[1],
      days_remaining: row[2],
      return_deadline: row[3]
    }));
    
    return {
      success: true,
      data: {
        totalDevices,
        borrowedDevices,
        availableDevices,
        overdueDevices,
        deviceTypeDistribution,
        borrowStatusByType,
        upcomingReturns
      }
    };
  } catch (error) {
    console.error('stats:dashboard error:', error);
    return {
      success: false,
      error: error.message
    };
  }
});
```

```javascript
const bcrypt = require('bcryptjs');

ipcMain.handle('user:login', async (event, { username, password }) => {
  try {
    const db = getDatabase();
    
    const result = db.exec(
      'SELECT password, password_hint FROM users WHERE username = ?',
      [username]
    );
    
    if (result[0]?.values.length === 0) {

      };

    return {
      success: true,

        password_hint
      }
    };
```

```typescript
// src/pages/Borrow/components/BorrowModal.tsx
import React, { useEffect, useState } from 'react';
import {
  Modal,
  Form,
  Select,
  Input,
  DatePicker,
  message,
} from 'antd';
import { listDevices } from '@/services/device';
import { createBorrowRecord } from '@/services/borrow';

interface BorrowModalProps {
  visible: boolean;
  onClose: () => void;
  onSuccess: () => void;
}

export default function BorrowModal({
  visible,
  onClose,
  onSuccess,
}: BorrowModalProps) {
  const [form] = Form.useForm();
  const [loading, setLoading] = useState(false);
  const [deviceTypes, setDeviceTypes] = useState([]);
  const [availableDevices, setAvailableDevices] = useState([]);

  useEffect(() => {
    if (visible) {
      loadDeviceTypes();
    }
  }, [visible]);

  const loadDeviceTypes = async () => {
    // 加载设备类型列表
    const result = await listDevices({ status: 'available' });
    if (result.success) {
      const types = [...new Set(result.data.list.map((d: any) => d.name))];
      setDeviceTypes(types);
    }
  };

  const handleDeviceTypeChange = async (deviceType: string) => {
    // 根据设备类型加载可借设备
    const result = await listDevices({
      name: deviceType,
      status: 'available',
    });
    if (result.success) {
      setAvailableDevices(result.data.list);
    }
    form.setFieldsValue({ device_id: undefined });
  };

  const handleSubmit = async () => {
    try {
      const values = await form.validateFields();
      setLoading(true);

      const result = await createBorrowRecord({
        ...values,
        borrow_time: values.borrow_time.toISOString(),
        return_deadline: values.return_deadline.toISOString(),
      });

      if (result.success) {
        message.success('借出记录创建成功');
        form.resetFields();
        onSuccess();
      } else {
        message.error(result.error || '创建失败');
      }
    } catch (error) {
      console.error('Submit error:', error);
    } finally {
      setLoading(false);
    }
  };

  return (
    <Modal
      title="借出设备"
      open={visible}
      onCancel={onClose}
      onOk={handleSubmit}
      confirmLoading={loading}
      width={600}
    >
      <Form
        form={form}
        labelCol={{ span: 6 }}
        wrapperCol={{ span: 16 }}
      >
        <Form.Item
          name="device_type"
          label="设备类型"
          rules={[{ required: true, message: '请选择设备类型' }]}
        >
          <Select
            placeholder="请选择"
            showSearch
            onChange={handleDeviceTypeChange}
          >
            {deviceTypes.map((type) => (
              <Select.Option key={type} value={type}>
                {type}
              </Select.Option>
            ))}
          </Select>
        </Form.Item>
        <Form.Item
          name="device_id"
          label="设备编号"
          rules={[{ required: true, message: '请选择设备编号' }]}
        >
          <Select
            placeholder="请选择"
            showSearch
            filterOption={(input, option) =>
              option?.children?.toLowerCase().includes(input.toLowerCase())
            }
          >
            {availableDevices.map((device: any) => (
              <Select.Option key={device.id} value={device.id}>
                {device.code} ({device.brand})
              </Select.Option>
            ))}
          </Select>
        </Form.Item>
        <Form.Item
          name="borrower_name"
          label="借用人"
          rules={[
            { required: true, message: '请输入借用人姓名' },
            { max: 20, message: '姓名不能超过20个字符' },
          ]}
        >
          <Input placeholder="请输入" />
        </Form.Item>
        <Form.Item
          name="borrower_class"
          label="班级"
          rules={[
            { required: true, message: '请输入班级' },
            { max: 50, message: '班级不能超过50个字符' },
          ]}
        >
          <Input placeholder="请输入" />
        </Form.Item>
        <Form.Item
          name="borrower_student_id"
          label="学号"
          rules={[
            { required: true, message: '请输入学号' },
            { len: 10, message: '学号必须为10位' },
          ]}
        >
          <Input placeholder="请输入10位学号" maxLength={10} />
        </Form.Item>
        <Form.Item
          name="borrower_phone"
          label="联系方式"
          rules={[
            { required: true, message: '请输入联系方式' },
            { pattern: /^1[3-9]\d{9}$/, message: '请输入正确的手机号' },
          ]}
        >
          <Input placeholder="请输入11位手机号" maxLength={11} />
        </Form.Item>
        <Form.Item
          name="borrow_time"
          label="借出时间"
          rules={[{ required: true, message: '请选择借出时间' }]}
          initialValue={moment()}
        >
          <DatePicker showTime style={{ width: '100%' }} />
        </Form.Item>
        <Form.Item
          name="return_deadline"
          label="应还时间"
          rules={[
            { required: true, message: '请选择应还时间' },
            ({ getFieldValue }) => ({
              validator(_, value) {
                if (!value || !getFieldValue('borrow_time')) {
                  return Promise.resolve();
                }
                if (value.isAfter(getFieldValue('borrow_time'))) {
                  return Promise.resolve();
                }
                return Promise.reject(
                  new Error('应还时间必须晚于借出时间')
                );
              },
            }),
          ]}
        >
          <DatePicker showTime style={{ width: '100%' }} />
        </Form.Item>
      </Form>
    </Modal>
  );
}
```

## 10. 常见问题
### 10.1 数据库问题
**Q: 数据库文件存放在哪里？**

A: 数据库文件存放在 Electron 的 `userData` 目录：

+ Windows: `C:\Users\<username>\AppData\Roaming\device-management-system\database.sqlite`
+ macOS: `~/Library/Application Support/device-management-system/database.sqlite`

**Q: 如何备份数据库？**

A: 复制上述路径中的 `database.sqlite` 文件即可。

**Q: 如何重置数据库？**

A: 删除 `database.sqlite` 文件，重启应用会自动创建新的数据库。

### 10.2 开发问题
**Q: Electron 窗口无法加载 Umi 页面？**

A: 检查以下几点：

1. Umi 开发服务器是否正常运行（[http://localhost:8000）](http://localhost:8000）)
2. Electron 主进程是否正确加载该地址
3. 检查控制台错误信息

**Q: IPC 通信失败？**

A: 检查：

1. preload.js 是否正确配置
2. contextIsolation 是否开启
3. ipcMain.handle 和 ipcRenderer.invoke 的 channel 名称是否一致

**Q: 打包后应用无法启动？**

A: 检查：

1. package.json 的 main 字段是否正确指向主进程文件
2. 所有依赖是否正确打包到 app.asar
3. 查看应用日志文件（位于 userData 目录）

### 10.3 性能问题
**Q: 表格数据量大时加载慢？**

A: 解决方案：

1. 使用分页加载
2. 实现虚拟滚动（antd Table 的 `virtual` 属性）
3. 优化 SQL 查询，添加索引

**Q: 应用启动慢？**

A: 优化方案：

1. 使用代码分割（React.lazy + Suspense）
2. 延迟加载非关键模块
3. 优化数据库初始化流程
